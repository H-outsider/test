# 新建文档

## 1.1 与其他语言相比，使用 Go 有什么好处？

Go 语法简洁、规范统一，注重开发效率与代码可读性，并通过协程和高效的 GMP 调度模型提供出色的并发能力；同时，其支持并行垃圾回收，内存管理效率较高。

## 1.2 什么是协程？

协程（Goroutine）是由用户态调度的轻量级线程，使用 `go` 关键字即可启动并发执行的函数。它以很小的栈空间启动，并能按需自动伸缩，因此可以高效支持大量协程同时运行。

## 1.3 协程、线程和进程有什么区别？

进程拥有独立的内存空间，隔离性强但创建和切换开销较大；线程由操作系统调度并共享所属进程的资源，开销较小但需要处理并发安全问题。协程则由语言运行时在用户态调度，并依托线程执行，创建和切换成本更低，适合处理大量并发任务。

## 1.4 Go 中 `make` 和 `new` 有什么区别？

`make` 只用于初始化 `slice`、`map` 和 `channel`，返回可直接使用的值；`new` 可为任意类型分配一块置为零值的内存，并返回指向它的指针。

## 1.5 Go 中数组和切片有什么区别？

数组长度固定且属于类型的一部分（如 `[3]int` 和 `[4]int` 是不同类型），赋值或传参时会复制整个数组；切片长度可变，是包含底层数组指针、长度和容量的轻量级描述结构。切片本身同样按值传递，但复制后的切片通常共享底层数组，使用 `append` 扩容时也可能重新分配新的底层数组。

## 1.6 使用 `for range` 时，迭代变量的地址会变化吗？

Go 1.22 之前，循环中用 `:=` 声明的迭代变量通常被各轮循环复用，因此取地址会得到同一个变量；从 Go 1.22 开始，每轮循环都会创建新的迭代变量，所以地址不同，也避免了闭包或指针误用同一变量的问题。

## 1.7 如何高效地拼接字符串？

少量固定字符串可直接使用 `+`，已有字符串切片适合用 `strings.Join`，循环或动态拼接则优先使用 `strings.Builder`，并可通过 `Grow` 预分配容量来减少内存分配。`bytes.Buffer` 更适合同时处理字节数据，`fmt.Sprintf` 格式化灵活但通常开销较大。

## 1.8 `defer` 的执行顺序和使用场景是什么？

`defer` 会在当前函数返回前按后进先出（LIFO）的顺序执行，即后声明的先执行，常用于关闭文件、释放锁或连接等资源清理。普通返回值在执行 `defer` 前已经确定，而命名返回值仍可被延迟函数修改。

## 1.9 什么是 `rune` 类型？

`rune` 是 `int32` 的别名，用于表示一个 Unicode 码点，适合处理中文等多字节字符；`byte` 是 `uint8` 的别名，通常表示原始字节。对字符串使用 `len` 得到的是字节数，如需统计 Unicode 码点可使用 `utf8.RuneCountInString` 或转换为 `[]rune`。

## 1.10 Go 语言中的结构体标签（tag）有什么用？

结构体标签是附加在字段上的元数据，供 JSON、数据库映射、表单绑定和参数校验等使用，例如 ``json:"name"``、``db:"name"`` 和 ``binding:"required"``。标签本身不会自动产生效果，必须由相应库通过反射读取并解释。

## 1.11 Go 打印时 `%v`、`%+v` 和 `%#v` 有什么区别？

`%v` 按默认格式输出值，`%+v` 在打印结构体时额外显示字段名，`%#v` 则输出接近 Go 源代码的完整表示，通常还包含类型信息。

## 1.12 Go 中空结构体 `struct{}` 占用空间吗？

空结构体不包含任何字段，单个值的大小由 `unsafe.Sizeof(struct{}{})` 得到 `0`，因此适合表示只关心“是否存在”而不需要存储数据的场景。

## 1.13 空结构体 `struct{}` 有什么用途？

空结构体常用作 `map[T]struct{}` 的值来实现集合（Set），也可通过 `chan struct{}` 传递完成、通知等无数据含义的信号；它还可以作为只定义方法而不保存状态的类型。

## 1.14 `init()` 函数什么时候执行？

程序启动时会先按依赖顺序初始化被导入的包，每个包先初始化包级变量，再执行其中的 `init()` 函数，最后才运行 `main()`。`init()` 不能带参数或返回值，也不能被代码主动调用，一个包或源文件中可以定义多个。

## 1.15 两个 `interface` 可以比较吗？

接口值可以使用 `==` 和 `!=` 比较：两个接口都为 `nil`，或动态类型相同且动态值相等时，结果为相等。若接口中保存了切片、映射或函数等不可比较类型，比较可能触发 `panic`；两个指针即使指向内容相同的对象，也只有地址相同时才相等。

## 1.16 两个看起来都是 `nil` 的值可能不相等吗？

可能：接口值只有在动态类型和动态值都为空时才等于 `nil`，而装入接口的“类型为 `*T`、值为 `nil`”的指针仍带有动态类型，因此该接口不等于 `nil`。判断接口是否为空时，需要区分“空接口”和“包含 typed nil 的接口”。

## 1.17 Go 语言函数传参是值传递还是引用传递？

Go 只有值传递，传入普通值会复制数据，传入指针则复制指针本身。切片、映射、通道和接口等值被复制后，内部仍可能引用相同的底层数据，所以函数内的修改有时能影响函数外部，但这并不属于引用传递。

## 1.18 如何判断对象分配在栈上还是堆上？

变量的位置由编译器通过逃逸分析决定：若变量可能在函数返回后继续被引用，通常会逃逸到堆上，否则可能留在栈上。可使用 `go build -gcflags="-m=2"` 查看编译器的逃逸分析信息，但具体结果可能随代码和 Go 版本变化。

## 1.19 Go 的多返回值是如何实现的？

多返回值是 Go 语言和调用约定共同支持的，编译器会按照当前 ABI 将各返回值放入寄存器或栈上的指定位置，再交给调用方接收。具体实现属于编译器细节，不能简单理解为所有返回值都固定保存在调用方栈帧中。

## 1.20 Go 语言中 `_` 有什么作用？

`_` 称为空白标识符，可用于忽略不需要的变量或多返回值，也可通过 `_ "包路径"` 匿名导入包，只执行该包的初始化逻辑而不直接引用其成员。它还常用于编译期接口实现检查，例如 `var _ io.Reader = (*T)(nil)`。

## 1.21 普通指针和 `unsafe.Pointer` 有什么区别？

普通指针（如 `*int`）类型明确，受编译器的类型检查；`unsafe.Pointer` 可在不同指针类型之间转换，但绕过了部分类型安全保证，只应在确有必要时使用。`unsafe.Pointer` 仍会被垃圾回收器视为指针，而 `uintptr` 只是整数，不会保持对象存活，错误转换或跨越对象边界运算可能导致未定义或不安全的行为。
